# PAD · Лабораторная работа №3 — конвертер валют (BNM)

Десктопный конвертер валют на **Go + Fyne** по официальному курсу Национального банка Молдовы.
Сделан по spec-driven development: сначала спецификации (`.specify/`, `specs/`), потом код.

## Запуск

```bash
go run .
```

Требования: Go 1.26+, на macOS — Xcode Command Line Tools (Fyne использует cgo).

## Тесты

```bash
go test ./...
```

Все unit-тесты работают без сети (сервер BNM подменяется `httptest`). Живая проверка реального bnm.md:

```bash
LAB3_LIVE=1 go test ./internal/bnm -run Live -v
```

## Возможности

| Требование | Как сделано |
|---|---|
| GUI | Окно Fyne: сумма, «Из валюты», «В валюту», кнопка обмена направлений, «Конвертировать», результат |
| Кнопка неактивна до заполнения | Активна только если курсы загружены, сумма не пустая и выбраны обе валюты |
| Дата и источник | Строка «Курс на ДД.ММ.ГГГГ · Источник: Национальный банк Молдовы (bnm.md)» |
| Обе стороны | Любая пара через MDL, в том числе MDL → валюта и валюта → валюта; учитывается `Nominal` |
| Одинаковые валюты | Результат = сумма, без ошибки |
| Некорректный ввод | Пусто, 0, минус, буквы, `1e5`, `NaN`, > 1e12 — сообщение под полем, конвертации нет |
| Выходные/праздники | Нет курса на дату → до 10 дней назад, сообщение «Курс на X не опубликован, используется курс от Y» |
| Нет сети | Сообщение «Нет соединения с bnm.md», работа с сохранённым курсом и его датой |
| Кэш | `~/Library/Caches/pad-lab3/rates.json` (macOS), атомарная запись, переживает перезапуск |

## Структура

```
main.go, ui.go        окно и обработчики
internal/bnm          разбор XML BNM, HTTP-клиент
internal/convert      пересчёт через MDL
internal/validate     проверка суммы и даты
internal/cache        JSON-кэш
internal/rates        стратегия загрузки: дата → предыдущие дни → кэш
specs/001-currency-converter   spec, plan, research, data-model, contracts, tasks
.specify/memory/constitution.md
```
